# Agent collaboration

**Status:** MANDATORY
**Triggers:** delegating work, selecting agent roles, integrating agent findings
**Enforced by:** review

## Must

- Read `AGENTS.md`, then the relevant role, skill, and rules before making a project change.
- Delegate only bounded work with clear file/behavior scope and explicit read-only or edit permissions.
- Prefer repository source, CI logs, and verified behavior over assumptions in prompt templates or prior notes.
- Consolidate delegated findings and independently validate the integrated result.
- Do not claim an agent, test, build, deployment, or review ran unless it actually did.
- Treat reference repositories as read-only unless the user explicitly authorizes edits to them.
